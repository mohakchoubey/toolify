⚡ Architectural Architectural Fix: Batched vs. Sequential Tool Execution

Sonnet 5 was hindered by sequential tool calls (requiring multiple network round-trips). Sonnet 5.5 introduces single-turn batched tool calls, drastically reducing execution latency and prompt re-processing overhead.

Sub-Agent Orchestration Dynamic

The FrontierCode "Max Effort" Score Drop Analysis

On FrontierCode 1.1 (mergeable PRs without human edits), Sonnet 5.5 scored 52.1% at Xhigh effort, but dropped to 46.2% at Max effort.

1.
Automatic Sub-Agent Decomposition:

At Max effort, Sonnet 5.5 systematically triggers Claude Code's code-review skill, delegating tasks across multiple autonomous sub-agents.

2.
Out-of-Scope Refactoring & Timeouts:

Sub-agents frequently initiated helpful, high-quality out-of-scope code cleanups or triggered session timeouts. FrontierCode strictly penalizes non-essential edits, lowering the PR merge score.

Engineering Recommendation

Avoid using Max effort on bounded software engineering tasks. Standard operational software development achieves peak cost-accuracy efficiency on Medium or High effort.
